# 세션 진행 대시보드 (Session Board)

Claude 데스크톱 앱(Code 탭)에서 여러 세션에 일을 시켰을 때, 세션마다 **지금 몇 번째 단계인지·걸린 시간과 예상 시간·백그라운드 작업이 살아 있는지·누가 내 답을 기다리는지**를 한 창에서 보여 줘요. "끝났어?" 라고 묻지 않아도 돼요.

- 항상 위에 뜨는 작은 창 하나(폭 330px). 맨 위 숫자 넷(봐야 할 것 · 일하는 중 · 쉬는 중 · 끝남)은 켜고 끄는 단추라, 켠 구역의 세션만 아래에 줄로 나와요.
- 줄마다 제목·지금 단계·`단계 번호/전체 · 걸린/예상분`, 일하는 중이면 **끝 예상 시각**, 작업 목록에 예상 시간이 있으면 맨 아래 얇은 **진행 막대**.
- 줄 아이콘 밑 꺾쇠(또는 줄을 오른쪽 단추)로 **자세히·간단히**: 단계별 걸린/예상 시간, 도는 백그라운드 작업(CPU·로그 마지막 줄), 알람, 마지막 보고를 그 줄 아래에 펼쳐요.
- 줄을 누르면 Claude 앱의 그 세션으로 바로 이동.
- 예상 시간을 넘긴 단계·답을 기다리는 세션은 깜빡이는 `!` 로. 창 테두리는 가장 급한 구역의 색(막힘 빨강 > 진행 파랑 > 쉬는 중 회색 > 끝남 초록)으로 천천히 숨쉬어요.
- **항상 위** 단추(켜고 끄기), 다크 모드, 하트비트 캐릭터(대시보드가 살아 있는지).
- 트레이 아이콘에 봐야 할 것·일하는 중 숫자 배지. 오른쪽 단추 메뉴: 대시보드 보기 · **업데이트 확인** · 끝내기. 켤 때 하루 한 번 새 버전을 조용히 확인해요.
- 한 번만 실행돼요. 다시 실행하면 떠 있는 창이 앞으로 나와요.

Windows 10/11 · Claude 데스크톱 앱 전용 · 화면 글은 한국어예요. 0.4.0 부터 Rust 로 다시 만들어 설치 크기 약 21MB(예전 126MB), 메모리 절반이에요.

## 설치

1. **대시보드**: [최신 릴리스](https://github.com/morulab-taesoo/session-board-releases/releases/latest)에서 `SessionBoard-Setup-<버전>.exe` 를 받아 실행해요(관리자 권한 필요 없음). 서명이 없어서 SmartScreen 경고가 뜨면 '추가 정보 → 실행'.
2. **훅 플러그인**(권장): 세션이 작업 목록을 놓치지 않게 붙잡고, 예상 시간을 넘기면 중간 점검·재계산을 하게 해요. 대시보드를 먼저 설치하세요(플러그인이 설치된 `SessionBoardHook.exe` 를 불러요).
   ```powershell
   claude plugin marketplace add morulab-taesoo/session-board-releases
   claude plugin install session-board@session-board
   ```
   그 뒤 Claude 앱 세션에서 `/reload-plugins`(또는 앱 다시 시작). 플러그인이 없으면 대시보드에 주황 안내가 떠요.

[모드 런처](https://github.com/morulab-taesoo/mod-launcher-releases)를 쓰면 둘 다 런처에서 설치할 수 있어요: 앱 '세션 진행 대시보드', 모드 '세션 진행 대시보드 훅'.

## 세션이 진행을 잘 보이게 하려면

플러그인이 세션 시작 때 알려 주는 규칙이에요(직접 지켜도 돼요):
- 작업 목록 단계 이름 끝에 예상 시간을 `(~30분)`처럼 적기
- 단계를 마칠 때마다 넘기기, 턴을 마칠 때 남은 단계는 완료나 `(보류: 이유)`로
- 예상을 넘기면 중간 점검하고 `(~50분, 재계산)`처럼 다시 적기
- 오래 걸리는 명령은 백그라운드로 + 로그 파일로, 기다리며 쉴 땐 예상 끝 시각 알람(`sleep`)

## 개인정보·한계

- 대화 기록은 **이 PC 안에서만** 읽어요. 밖으로 보내는 건 새 버전 확인(GitHub)뿐이에요.
- Claude 데스크톱 앱의 내부 파일 형식을 읽어요. 앱이 업데이트되면 일부가 안 보일 수 있어요(새 버전에서 맞춰요).
- 클라우드 세션은 이 PC 에 기록이 없어서 안 보여요.
- 대시보드가 갑자기 꺼지면 이유가 `%LOCALAPPDATA%\SessionBoard\crash.log` 에 남아요(0.4.1 부터). 문제를 알릴 때 함께 보내 주세요.

## 지우기

설정 → 앱에서 '세션 진행 대시보드' 제거. 플러그인은 `claude plugin uninstall session-board@session-board`(또는 모드 런처에서 제거).

## 라이선스 고지

화면은 [Qt for Python (PySide6)](https://www.qt.io/qt-for-python)(LGPLv3)를 고치지 않고 동적으로 써요. 프로세스 정보는 [psutil](https://github.com/giampaolo/psutil)(BSD-3)을 써요.
